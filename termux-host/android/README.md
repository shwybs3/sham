# ShamHost — تطبيق أندرويد

تطبيق أصلي (APK) يرافق نظام ShamHost. يعمل بدوره الطبيعي على **الجوال الآخر** كواجهة للوحة التحكم،
ويعمل أيضاً على **الجوال المستضيف** كأداة تشغيل وإيقاف لخدمات Termux.

## ما يفعله

| الشاشة | الوظيفة |
|---|---|
| الإعداد | إدخال عنوان الخادم، أو **بحث تلقائي** يفحص الشبكة المحلية ويجد الجوال المستضيف وحده |
| اللوحة | عرض لوحة ShamHost كاملة مع دعم رفع الملفات وتنزيلها من مدير الملفات |
| تحكم Termux | تشغيل / إيقاف / إعادة تشغيل / حالة / doctor / كلمة مرور — بضغطة واحدة بدل كتابة الأوامر |

البحث التلقائي يفحص نطاق `/24` الحالي على منفذ اللوحة، ويتحقق أن الرد فعلاً من ShamHost قبل عرضه،
فلا يعطيك أجهزة أخرى تصادف أن منفذها مفتوح.

## التثبيت

1. انقل `ShamHost.apk` إلى الجوال
2. فعّل **تثبيت التطبيقات من مصادر غير معروفة** لتطبيق الملفات أو المتصفح
3. افتح الملف وثبّته

التطبيق موقّع بمفتاح تطوير خاص بالمشروع، لذلك سيحذّرك أندرويد أنه ليس من متجر Play. هذا متوقع.

## تفعيل التحكم بـ Termux

شاشة التحكم ترسل الأوامر إلى Termux عبر واجهة `RUN_COMMAND` الرسمية. لتعمل، نفّذ في Termux مرة واحدة:

```bash
mkdir -p ~/.termux
echo 'allow-external-apps = true' >> ~/.termux/termux.properties
termux-reload-settings
```

ثم أغلق Termux وافتحه من جديد. بدون هذا السطر سيرفض Termux الأوامر القادمة من أي تطبيق خارجي — وهذا سلوك أمني مقصود.

## البناء من المصدر

لا يحتاج Gradle ولا اتصالاً بـ Maven، فقط JDK و Android SDK:

```bash
sdkmanager "platforms;android-34" "build-tools;35.0.0"
export ANDROID_HOME=$HOME/android-sdk
bash build.sh
# → build/ShamHost.apk
```

متغيرات اختيارية: `VERSION_NAME` و `VERSION_CODE` و `KEYSTORE` و `KEYSTORE_PASS` و `MIN_API`.

يُنشئ السكربت مفتاح توقيع محلياً عند أول بناء (`shamhost.keystore`) وهو **مستثنى من Git** عمداً.
للنشر بمفتاحك الخاص مرّر `KEYSTORE=/path/to/key.jks KEYSTORE_PASS=...`.

> ملاحظة على أدوات البناء: `d8` في `build-tools` 34 وما دونه ينهار على الفئات المجهولة عند تشغيله
> بـ JDK 21، لذلك الحد الأدنى هنا هو `35.0.0`.

## البنية

```
AndroidManifest.xml
build.sh                 بناء كامل بـ aapt2 + javac + d8 + apksigner
res/                     تخطيطات وموارد عربية (وإنجليزية في values-en)
src/com/shamhost/panel/
  SetupActivity.java     الإعداد والبحث التلقائي
  WebActivity.java       عرض اللوحة، الرفع، التنزيل، التنقل
  ControlActivity.java   أوامر Termux
  Discovery.java         فحص الشبكة المحلية
  Termux.java            واجهة RUN_COMMAND
  Prefs.java             حفظ الإعدادات
```

بلا أي اعتماديات خارجية — لا AndroidX ولا مكتبات طرف ثالث. حجم الحزمة ‎~42KB.

## المتطلبات

أندرويد 5.0 (API 21) فأحدث. لا يحتاج روت.
