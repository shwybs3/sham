# ربط دومين Namecheap بجهازك — دليل كامل

## الجزء الأول: تفعيل واجهة API

واجهة Namecheap API تحتاج شرطين لا ثالث لهما: تفعيل الوصول، وإدراج عنوان IP الخاص بك في قائمة بيضاء.

1. سجّل الدخول إلى `namecheap.com`
2. اذهب إلى **Profile ← Tools**
3. انزل إلى **Namecheap API Access** واضغط **Manage**
4. فعّل المفتاح (**ON**). قد يطلب منك Namecheap استيفاء شرط واحد على الأقل:
   - رصيد 50 دولاراً في الحساب، أو
   - 20 دولاراً مصروفة خلال آخر سنتين، أو
   - 10 دومينات في الحساب
5. انسخ **API Key**
6. في نفس الصفحة، أضف عنوان IP الخارجي لجهازك في **Whitelisted IPs**

للحصول على عنوانك: افتح اللوحة ← **الإعدادات** ← بجانب حقل IP اضغط **اكتشف تلقائياً**.
أو في الطرفية:

```bash
curl -s https://api.ipify.org
```

> **مهم:** عنوان IP على شبكة الجوال يتغير باستمرار. كلما تغيّر، ستفشل استدعاءات API برسالة
> `Invalid request IP`. عندها حدّث العنوان في مكانين: قائمة Namecheap البيضاء، وحقل IP في إعدادات اللوحة.
> إن كان هذا مزعجاً، استخدم **DNS الديناميكي** بدلاً من API — فهو لا يتطلب قائمة بيضاء إطلاقاً.

## الجزء الثاني: إدخال البيانات في اللوحة

**الإعدادات ← Namecheap API**

| الحقل | القيمة |
|---|---|
| ApiUser | اسم مستخدمك في Namecheap |
| UserName | نفس الاسم عادةً |
| API Key | المفتاح المنسوخ |
| IP | عنوانك الخارجي |

اضغط **حفظ**، ثم اذهب إلى **الدومينات و DNS** — إن ظهرت قائمة دوميناتك عند الضغط على «دوميناتي»، فالاتصال ناجح.

## الجزء الثالث: توجيه الدومين

### الحالة أ — تستخدم نفق Cloudflare (الأكثر عملية)

النفق لا يحتاج سجلات DNS في Namecheap إطلاقاً، بل يحتاج نقل الدومين إلى خوادم أسماء Cloudflare:

1. أنشئ حساباً مجانياً على `cloudflare.com` وأضف دومينك
2. ستعطيك Cloudflare اسمي خادمين مثل `ana.ns.cloudflare.com` و `bob.ns.cloudflare.com`
3. في اللوحة: **الدومينات و DNS ← خوادم الأسماء** ← الصق الاسمين ← **تعيين**
4. انتظر الانتشار (من دقائق إلى 24 ساعة)
5. أنشئ النفق كما في الدليل الرئيسي، وأضف Public Hostname يربط دومينك بـ `http://localhost:8080`

عند هذه النقطة يتولى Cloudflare إنشاء سجل DNS للنفق تلقائياً، وتحصل على HTTPS بلا أي إعداد إضافي.

### الحالة ب — لديك IP عام ثابت

**الدومينات و DNS ← ربط سريع**:

1. اكتب الدومين
2. اضغط **استخدم IP جهازي**
3. اضغط **ربط**

سيُنشئ النظام سجلي A للجذر و www. ثم وجّه في راوترك:

| من الخارج | إلى الجوال |
|---|---|
| 80 | 8080 |
| 443 | 8443 |

### الحالة ج — IP عام لكنه متغيّر

**الدومينات و DNS ← DNS ديناميكي**:

1. في حساب Namecheap: **Domain List ← Manage ← Advanced DNS** ← فعّل **Dynamic DNS**
2. انسخ **Dynamic DNS Password**
3. في اللوحة: أدخل المضيف (`@` للجذر) والدومين وكلمة المرور ← **حفظ وتحديث**
4. كرّر لكل مضيف تريده (`www` مثلاً)

استخدم زر **مزامنة كل السجلات الآن** عند تغيّر عنوانك.

## إدارة السجلات يدوياً

**الدومينات و DNS ← سجلات DNS** ← اكتب الدومين ← **تحميل**.

تظهر كل السجلات الحالية، ويمكنك إضافة أو تحديث أو حذف أي سجل.
النظام يدمج تغييرك مع السجلات القائمة قبل الإرسال، لأن أمر `setHosts` في Namecheap
يستبدل كامل مجموعة السجلات — من يستدعيه مباشرة بسجل واحد يمحو باقي DNS بالكامل.

## أخطاء شائعة

| الرسالة | السبب والحل |
|---|---|
| `Invalid request IP` | عنوانك غير مدرج في القائمة البيضاء، أو تغيّر. حدّثه في الموقع وفي الإعدادات |
| `API Key is invalid` | المفتاح خاطئ أو التفعيل معطّل |
| `Domain not found` | الدومين ليس في هذا الحساب، أو خوادم أسمائه منقولة لمزوّد آخر |
| السجلات لا تظهر بعد التعديل | خوادم الأسماء ليست خوادم Namecheap. سجلات Namecheap لا تُقرأ عندها |
| الموقع لا يفتح رغم صحة DNS | انتشار DNS لم يكتمل، أو المنافذ غير موجّهة. جرّب النفق بدلاً منه |
