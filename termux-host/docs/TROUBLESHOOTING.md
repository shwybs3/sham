# حل المشاكل

ابدأ دائماً بهذين الأمرين، فهما يكشفان معظم الحالات:

```bash
shamhost doctor
shamhost status
```

---

## اللوحة لا تفتح من الجوال الآخر

1. تأكد أن الجهازين على **نفس شبكة الواي فاي**
2. نفّذ `shamhost url` واستخدم العنوان المطبوع بالضبط
3. بعض الراوترات تفعّل **AP Isolation** الذي يمنع الأجهزة من رؤية بعضها — عطّله من إعدادات الراوتر
4. تحقق أن اللوحة تعمل: `shamhost status` يجب أن تُظهر `panel` باللون الأخضر
5. راجع السجل: `shamhost logs panel`

## نسيت كلمة مرور اللوحة

```bash
shamhost password
```

يطبع كلمة مرور جديدة عشوائية. أو حدّد واحدة: `shamhost password كلمتي_الجديدة`

## nginx لا يبدأ

```bash
nginx -t -c $HOME/.shamhost/conf/nginx.conf -p $PREFIX
```

يطبع الخطأ ورقم السطر بدقة. الأسباب المتكررة:

- **Address already in use** — المنفذ 8080 مشغول. اعرف من يشغله: `ss -lptn 2>/dev/null | grep 8080`
- **unknown directive** — نسخة nginx قديمة. حدّث: `pkg upgrade nginx`
- ملف vhost تالف — من اللوحة: **الإعدادات ← إعادة بناء إعدادات nginx**

## PHP لا يعمل ويُنزَّل الملف بدل تنفيذه

يعني أن nginx لا يمرّر الطلب إلى PHP-FPM:

```bash
shamhost service php-fpm restart
shamhost logs php
```

تأكد أن نوع الموقع **php** وليس **static** (من اللوحة: المواقع ← فتح).

## MariaDB لا تعمل

```bash
shamhost logs mariadb
```

إن ظهر خطأ في التهيئة، أعد بناء قاعدة البيانات (⚠ يمسح كل القواعد):

```bash
shamhost service mariadb stop
rm -rf $PREFIX/var/lib/mysql
mysql_install_db
shamhost service mariadb start
```

إن كان الخطأ `Access denied`، فالمستخدم الإداري في الإعدادات خاطئ.
في Termux يكون اسم مستخدم النظام: نفّذ `whoami` وضع الناتج في **الإعدادات ← اتصال MariaDB**.

## الخادم يتوقف عندما أقفل الشاشة

هذا سلوك أندرويد الافتراضي، وعلاجه ثلاث خطوات:

1. `termux-wake-lock` (يُشغَّل تلقائياً مع `shamhost start`)
2. إعدادات النظام ← التطبيقات ← Termux ← البطارية ← **بدون قيود / Unrestricted**
3. في بعض الأجهزة (شاومي، هواوي، أوبو، سامسونج) اقفل Termux في قائمة التطبيقات الحديثة

## الخادم لا يعمل بعد إعادة تشغيل الجهاز

ثبّت **Termux:Boot** من F-Droid وافتحه مرة واحدة. سكربت الإقلاع مكتوب مسبقاً في
`~/.termux/boot/00-shamhost`.

## نفق Cloudflare يتوقف بعد فترة

- النفق **المؤقت** له عمر محدود بطبيعته. استخدم النفق الدائم للاستضافة الجادة.
- راجع سجل النفق من اللوحة: **الأنفاق ← سجل**
- إن كان السبب انقطاع الشبكة، أضف مهمة مجدولة لإعادة التشغيل، أو أعد تشغيله من اللوحة.

## فشل إصدار شهادة SSL

الرسالة الكاملة تظهر في نافذة منبثقة. الأسباب الشائعة:

| العرض | الحل |
|---|---|
| `Invalid request IP` | حدّث IP في القائمة البيضاء وفي الإعدادات |
| `Could not find DNS record` | زد مهلة الانتشار، أو تحقق أن الدومين يستخدم خوادم Namecheap |
| `rateLimited` | Let's Encrypt يسمح بـ 5 محاولات فاشلة للدومين في الساعة. انتظر |
| `acme.sh: not found` | `curl https://get.acme.sh \| sh` |

عند استخدام نفق Cloudflare لست بحاجة لشهادة محلية أصلاً.

## المساحة امتلأت

```bash
du -sh ~/.shamhost/* | sort -h
```

نظّف: **النسخ الاحتياطي ← احتفظ بآخر 5 نسخ**، واحذف السجلات القديمة من `~/.shamhost/logs/`.

## الموقع بطيء

- عدد عمال PHP في `~/.shamhost/conf/php-fpm.conf` مضبوط على 8 لتناسب ذاكرة الجوال. لا ترفعه إلا مع ذاكرة وفيرة.
- فعّل التخزين المؤقت في تطبيقك؛ تخزين الجوال أبطأ من SSD الخوادم.
- الصور الكبيرة تستهلك الشبكة والبطارية معاً — اضغطها قبل الرفع.

## إعادة ضبط كاملة

```bash
shamhost stop
rm -rf ~/.shamhost
cd ~/sham/termux-host && bash install.sh
```

⚠ يمسح كل المواقع والإعدادات. خذ نسخة احتياطية أولاً.
