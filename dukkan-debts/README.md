# دفتر ديون الدكان

منصة ويب حديثة كاملة لتسجيل ديون زبائن الدكان بدل الدفتر والقلم — بُنيت من الصفر بـ **Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + Prisma 7**، بتصميم عصري بالكامل، أيقونات احترافية (lucide-react)، وحركات وانتقالات سلسة (framer-motion).

## المميزات

### الموقع العام
- كروت زبائن عصرية تعرض الاسم، إجمالي الدين، وعدد العمليات — مرتبة تلقائياً حسب الأكبر ديناً.
- بحث فوري مع اقتراحات أسماء تظهر بمجرد كتابة حرفين (فلترة محلية فورية بدون أي تأخير شبكة).
- صفحة كل زبون: سجل كامل ومفصّل لكل عملية دين ودفعة بالتاريخ والوقت.
- إعلان نصي متحرك (Marquee) وبانرات صور قابلة للتفعيل من لوحة الإدارة.
- ودجت دردشة مباشرة عائم يسمح للزوار بالتواصل مع الدعم — نص، صور، وتسجيلات صوتية.
- إمكانية إخفاء الصفحة العامة بالكامل من الإعدادات إذا أردت خصوصية تامة.

### لوحة الإدارة (`/admin`)
- تسجيل دخول منفصل محمي بجلسات JWT (كوكي httpOnly) + معدّل محاولات لمنع الاختراق بالتخمين.
- **إضافة سريعة**: تسجيل دين أو دفعة بأقل من 10 ثوانٍ مع اقتراحات أسماء فورية وإنشاء زبون جديد تلقائياً عند الحاجة.
- إدارة كاملة للزبائن: تعديل البيانات، حذف الزبون (يحذف تلقائياً كل سجله)، "تسديد كامل الدين" بضغطة واحدة.
- تعديل أو حذف أي عملية من السجل مباشرة.
- إعدادات شاملة: اسم الدكان، الإعلان المتحرك، إظهار/إخفاء الصفحة العامة، تغيير كلمة المرور، إدارة البانرات.
- إدخال كل مفاتيح المنصات الخارجية من مكان واحد: Google OAuth، Cloudflare Turnstile، بوت تيليجرام.
- صندوق دردشة لإدارة كل محادثات الدعم والرد عليها مباشرة.

### قسم الخبز (`/bread`)
- قسم مستقل بالكامل لتسجيل شراء الخبز اليومي.
- تسجيل دخول بحساب Google (المفاتيح تُدخل من لوحة الإدارة، بدون الحاجة لتعديل الكود).
- واجهة فائقة السرعة: عدّاد كمية + زر تسجيل واحد، مع سجل شخصي لكل مستخدم.
- لوحة إدارة مستقلة لمتابعة كل الزبائن وتسجيلاتهم اليومية مع إمكانية التعديل والحذف.

## المكدس التقني

| الطبقة | التقنية |
|---|---|
| إطار العمل | Next.js 16 (App Router, Turbopack) |
| اللغة | TypeScript |
| التصميم | Tailwind CSS v4، خط Cairo، framer-motion |
| الأيقونات | lucide-react |
| قاعدة البيانات | SQLite عبر Prisma 7 (Driver Adapter: `@prisma/adapter-better-sqlite3`) |
| المصادقة | جلسات JWT موقّعة (jose) + bcrypt لكلمات المرور |
| رفع الملفات | تخزين محلي في `public/uploads` |

> **ملاحظة مهمة حول الاستضافة**: على عكس النسخة السابقة (PHP/MySQL)، هذا التطبيق مبني بـ Next.js ويحتاج **استضافة تدعم Node.js**. استضافة cPanel العادية (رفع ملفات PHP فقط) لا تكفي، لكن إذا كانت خطتك تتضمن ميزة "Setup Node.js App" (متوفرة بأغلب خطط cPanel Business عبر CloudLinux)، فهي تعمل ممتاز — راجع **[DEPLOY-CPANEL.md](./DEPLOY-CPANEL.md)** لدليل خطوة بخطوة. البدائل: VPS بسيط، أو Railway/Render (وليس Vercel، لأن نظام ملفاته مؤقت ولا يحفظ قاعدة بيانات SQLite).

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # ثم عدّل AUTH_SECRET بمفتاح عشوائي خاص بك
npx prisma migrate dev
npm run dev
```

افتح `http://localhost:3000/admin/setup` لإنشاء اسم الدكان وحساب الإدارة الأول (يظهر تلقائياً إذا لم يوجد أي حساب إدارة بعد).

## البناء للإنتاج

```bash
npm install
npx prisma migrate deploy
npm run build
npm run start
```

### متغيرات البيئة المطلوبة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | مسار ملف قاعدة بيانات SQLite، مثال: `file:./prod.db` |
| `AUTH_SECRET` | مفتاح عشوائي (64 حرف hex) لتوقيع جلسات الدخول — أنشئه بـ: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| `NEXT_PUBLIC_SITE_URL` | الرابط الكامل للموقع (يُستخدم لبناء رابط إعادة التوجيه لتسجيل الدخول بجوجل) |

## تفعيل تسجيل الدخول بجوجل (قسم الخبز)

1. أنشئ مشروع OAuth من [Google Cloud Console](https://console.cloud.google.com/apis/credentials).
2. أضف رابط إعادة التوجيه: `https://your-domain.com/api/bread/auth/google/callback`
3. انسخ الـ Client ID والـ Client Secret وأدخلهما من لوحة الإدارة → الإعدادات → مفاتيح المنصات الخارجية.

## هيكلة المشروع

```
src/
  app/                    # صفحات ومسارات App Router
    admin/(auth)/         # تسجيل الدخول + الإعداد الأولي (بدون قائمة جانبية)
    admin/(dashboard)/    # لوحة الإدارة الكاملة (محمية بـ proxy.ts)
    api/                  # كل واجهات الـ API
    bread/                # قسم الخبز العام
    customer/[id]/        # صفحة تفاصيل الزبون العامة
  components/
    admin/  bread/  chat/  site/  ui/
  lib/                    # Prisma client، المصادقة، الإعدادات، أدوات مشتركة
prisma/
  schema.prisma           # مخطط قاعدة البيانات
```

## الأمان

- كلمات المرور مشفّرة بـ bcrypt (12 rounds).
- جلسات موقّعة بـ JWT في كوكي `httpOnly` + `sameSite=lax`.
- معدّل محاولات على تسجيل دخول الإدارة لمنع هجمات التخمين.
- التحقق من الصلاحيات في كل مسار API إدارة (دفاع متعدد الطبقات، لا يُعتمد فقط على الـ proxy).
- تحقق صارم بـ Zod على كل مدخلات النماذج والـ API.
