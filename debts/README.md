# دفتر الدكان — منصة تسجيل ديون المحل

بديل كامل عن دفتر الديون الورقي: يسجّل كل زبون ودينه، بحث فوري بالاسم،
تسجيل سريع للعمليات (مشتريات/دفعات)، ولوحة إدارة كاملة.

## 1) إعداد قاعدة البيانات
أنشئ قاعدة بيانات MySQL فارغة، ثم استوردها:
```
mysql -u USERNAME -p DBNAME < schema.sql
```
هذا ينشئ الجداول (customers, transactions, settings, admin_users)
ويضيف 3 زبائن تجريبيين — احذفهم لاحقًا من لوحة الإدارة إن أردت.

## 2) بيانات الاتصال
افتح `includes/db.php` وعدّل:
```php
$DB_HOST = 'localhost';
$DB_NAME = 'shop_debts';
$DB_USER = 'shop_debts_user';
$DB_PASS = 'CHANGE_ME';
```

## 3) إنشاء أول حساب إداري
ارفع كل الملفات إلى الاستضافة، ثم افتح في المتصفح:
```
https://yourdomain.com/setup.php
```
أنشئ اسم مستخدم وكلمة مرور، ثم **احذف setup.php فورًا** من الاستضافة
لأسباب أمنية (لا يمكن لأحد إنشاء حساب إداري ثانٍ إن نسيت حذفه).

## 4) تسجيل الدخول للوحة الإدارة
```
https://yourdomain.com/admin/login.php
```

## البنية
```
index.php              الرئيسية العامة — بحث + كروت الزبائن
customer.php            صفحة تفاصيل زبون (عامة، للعرض فقط)
setup.php               إنشاء أول حساب إداري (احذفه بعد الاستخدام)
api/search.php          بحث فوري بالاسم (تكملة تلقائية)

admin/login.php          تسجيل الدخول
admin/index.php          نظرة عامة + أكبر الديون
admin/quick-entry.php     شاشة التسجيل السريع (الأهم للاستخدام اليومي)
admin/customers.php       إدارة كل الزبائن (إضافة/حذف)
admin/customer.php        إدارة زبون واحد (تعديل، عمليات، تسديد، حذف)
admin/settings.php        اسم المحل، العملة، البنر الإعلاني
admin/api/search-customers.php   بحث للتسجيل السريع
admin/api/save-transaction.php   حفظ عملية عبر AJAX

includes/                دوال مشتركة + أيقونات SVG احترافية
assets/css/style.css     نظام التصميم الكامل (الألوان، الحركات، البطاقات)
schema.sql                مخطط قاعدة البيانات
```

## كيف يعمل الرصيد؟
لا يوجد عمود "رصيد" مخزَّن — يُحسب دائمًا مباشرة من سجل العمليات:
`مجموع المشتريات − مجموع الدفعات`. هذا يعني أن التعديل أو حذف أي عملية
من لوحة الإدارة يُحدّث الرصيد فورًا وبدقة، ولا يمكن أن "يختل" الرقم.

## شاشة التسجيل السريع (الاستخدام اليومي)
هذه الشاشة (`admin/quick-entry.php`) مصمَّمة لتكون أسرع من الدفتر والقلم:
1. اكتب أول حرفين من اسم الزبون → تظهر اقتراحات فورية (أو "زبون جديد" تلقائيًا)
2. اختر مشتريات أو دفعة
3. اكتب المبلغ، اضغط Enter → ينتقل للوصف
4. اضغط Enter مرة أخرى → يُحفظ فورًا (بدون إعادة تحميل الصفحة) ويعود المؤشر لخانة الاسم تلقائيًا

## الأمان
- كلمات المرور مشفّرة عبر `password_hash()` (bcrypt)
- حماية CSRF على كل نموذج
- جلسة إدارية منفصلة تمامًا عن الصفحات العامة (`admin_id` في الجلسة)
- الصفحات العامة (index.php, customer.php) للعرض فقط — لا يمكن للزوّار
  إضافة أو تعديل أي شيء من دون تسجيل دخول إداري

## ملاحظة حول ثبات الكود
تعلّمنا من مشكلة سابقة (سطر نص واحد فيه علامة اقتباس غير مُهرَّبة بشكل
صحيح كسر الصفحة بالكامل) أن أي بيانات ديناميكية تُمرَّر داخل `<script>`
يجب أن تمر عبر `json_encode()` وليس تجميع نص يدويًا — وهذا ما اتُّبع في
كل نقطة تفاعل هنا (`quick-entry.php` تحديدًا). إن أضفت أي نص عربي أو
معرَّف من المستخدم داخل كود جافاسكربت مستقبلًا، اتّبع نفس القاعدة.
