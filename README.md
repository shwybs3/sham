# yassota — دليل التثبيت

## المتطلبات
- PHP 8.0+ مع إضافات: `PDO_MySQL` `GD` `cURL`
- MySQL 5.7+ / MariaDB
- استضافة تدعم `.htaccess` (cPanel/LiteSpeed/Apache)

---

## خطوات التثبيت (10 دقائق)

### 1. رفع الملفات
ارفع كل محتويات الحزمة (المضغوطة) إلى `public_html` عبر FTP أو File Manager في cPanel

### 2. إنشاء قاعدة البيانات
من cPanel → MySQL Databases: أنشئ قاعدة بيانات ومستخدم جديد، واربط المستخدم بقاعدة البيانات (جميع الصلاحيات)

**لا تحتاج لاستيراد أي ملف SQL يدوياً** — الموقع يُنشئ ويُصحّح كل الجداول تلقائياً بمجرد صحة بيانات الاتصال أدناه

### 3. إعداد config.php
افتح `config.php` وعدّل السطور الأولى فقط:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'اسم_قاعدة_البيانات');
define('DB_USER', 'اسم_المستخدم');
define('DB_PASS', 'كلمة_المرور');
define('SITE_URL', 'https://yourdomain.com');  // ← غيّر هذا!
```

### 4. إنشاء حساب الأدمن (مرة واحدة فقط)
افتح في المتصفح:
```
https://yourdomain.com/install/create-admin.php?u=admin&p=كلمة_مرور_قوية
```
**احذف ملف `install/create-admin.php` فوراً بعد التنفيذ**

### 5. الدخول للوحة التحكم
```
https://yourdomain.com/admin.php
```

### 6. إعداد OpenRouter (للذكاء الاصطناعي)
- اذهب إلى **الإعدادات** في القائمة الجانبية
- أضف مفتاح OpenRouter API (مجاني من https://openrouter.ai/keys)
- يمكن إضافة عدة مفاتيح، كل واحد بسطر منفصل
- فعّل "التبديل التلقائي بين النماذج" للحصول على أفضل أداء

## استيراد 1000+ تطبيق جاهز

ملف `install/apps-import.sql` يحتوي على **1008 تطبيقات** بمحتوى عربي كامل جاهز للنشر:
```bash
mysql -u USER -p DATABASE_NAME < install/apps-import.sql
```
أو من cPanel → phpMyAdmin → Import.

**ملاحظة**: شغّل الموقع مرة واحدة أولاً (لينشئ الجداول)، ثم استورد الملف.

## الإعلانات

الموقع مهيأ مسبقاً لـ **Google AdSense** عبر وحدات `<ins class="adsbygoogle">` في كل صفحة داخل `ad_slot()`.
لا تظهر إعلانات حقيقية قبل موافقة AdSense على الموقع — لا تعديل مطلوب بعد الموافقة.

لتغيير معرّف الناشر: ابحث عن `ca-pub-XXXXXXXXXX` في `config.php` وبدّله بمعرّفك.

## ملاحظات للنشر

- اقتصر تعديل `config.php` على الأسطر العليا فقط (قاعدة البيانات و SITE_URL)
- مجلد `uploads/` يجب أن يكون قابلاً للكتابة: `chmod 755 uploads/`
- احذف مجلد `install/` بعد إنهاء الإعداد (أو على الأقل احذف `create-admin.php`)
- إذا ظهر خطأ SSL في الـ .htaccess، علّق سطرَي إعادة التوجيه إلى HTTPS حتى تفعّل شهادة SSL
