# Apkzilo — دليل التثبيت

## آخر الإصلاحات في هذه النسخة
- **OpenRouter**: قائمة النماذج المجانية القديمة (llama-3.1، gemma-2، mistral-7b...) لم تعد موجودة على OpenRouter، وهذا كان سبب فشل كل المحاولات. تم تحديثها لنماذج حالية + إضافة `openrouter/free` (الموجّه الرسمي التلقائي من OpenRouter) كضمان أخير لا يفشل أبداً، مع جلب حي لقائمة النماذج المجانية المتاحة فعلياً الآن.
- **زر التحميل**: كان يبقى بلا أي أثر إذا لم يُضف رابط تحميل للتطبيق. الآن: لا يمكن نشر تطبيق بدون رابط تحميل (يتحول تلقائياً لمسودة مع رسالة توضيحية)، وصفحة التحميل تعرض رسالة واضحة بدل عدّاد وهمي إذا لم يوجد رابط.
- **لوحة التحكم على الجوال**: القائمة الجانبية كانت تتكدس فوق المحتوى بالكامل. الآن قائمة منسدلة (Off-canvas) بزر همبرغر علوي، تماماً كتطبيقات الويب الحديثة.
- **تكبير/تصغير الصفحة**: تم قفل الزوم (`user-scalable=no`) على كل الصفحات لتبدو كتطبيق ثابت لا كصفحة ويب عادية.
- **حذفنا** ملف `sw.js` من الحزمة (Service Worker لشبكة إعلانات منفصلة تستخدم صلاحية الإشعارات) — احذفه من السيرفر إن كان لا يزال موجوداً؛ الإعلانات تعمل بالكامل عبر شريحة `tag.min.js` العادية بدون أي حاجة له.

## خطوات التثبيت (10 دقائق)

### 1. رفع الملفات
ارفع كل محتويات المجلد إلى `public_html` عبر FTP أو File Manager

### 2. إنشاء قاعدة البيانات
- من cPanel → MySQL Databases: أنشئ قاعدة بيانات ومستخدم واربطه بكل الصلاحيات
- **لا حاجة لاستيراد أي ملف SQL يدوياً** — الموقع يُنشئ ويُصحّح كل الجداول تلقائياً بمجرد صحة بيانات الاتصال في `config.php` (ملف `install/schema.sql` موجود فقط كمرجع اختياري)

### 3. إعداد config.php
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'اسم_قاعدة_البيانات');
define('DB_USER', 'اسم_المستخدم');
define('DB_PASS', 'كلمة_المرور');
define('SITE_URL', 'https://yourdomain.com');
```

### 4. إنشاء حساب الأدمن
افتح في المتصفح (مرة واحدة فقط):
```
https://yourdomain.com/install/create-admin.php?u=admin&p=كلمة_مرور_قوية
```
**احذف `install/create-admin.php` فوراً بعد التنفيذ**

### 5. الدخول للوحة التحكم
```
https://yourdomain.com/admin.php
```

### 6. ضبط الإعدادات
- في **الإعدادات**: أضف مفتاح (أو أكثر) OpenRouter API لتفعيل التوليد التلقائي — يمكن إضافة عدة مفاتيح، كل واحد بسطر
- المفتاح من: https://openrouter.ai/keys (مجاني)
- فعّل "التبديل التلقائي بين الموديلات المجانية" ليجرّب الموقع كل موديل مجاني متاح حتى ينجح
- من صفحة **اختبار الاتصال** في القائمة الجانبية: زر واحد يفحص قاعدة البيانات، الصلاحيات، ومفاتيح OpenRouter، ويعرض تقريراً كاملاً بأي مشكلة وحلها
- من صفحة **قاعدة البيانات**: يمكنك رؤية حالة كل جدول وعدد سجلاته، وزر "فحص وإصلاح" لإعادة إنشاء أي جدول ناقص فوراً

### 7. إضافة أول تطبيق
- اضغط **إضافة تطبيق**
- اكتب الاسم فقط ثم اضغط **Generate AI**
- ارفع الأيقونة وروابط التحميل
- انشر

## الإعلانات (Google AdSense)
كل صفحات الموقع تحمّل سكربت AdSense (`ca-pub-5506877998492189`) وتعرض وحدات إعلانية حقيقية
(`<ins class="adsbygoogle">`) داخل كل صندوق `.ad-zone` عبر `ad_slot()` في `config.php` — لا تظهر إعلانات
فعلية قبل موافقة AdSense على الموقع، ولا حاجة لأي تعديل بعد الموافقة.

ملاحظة: شبكة MoneyTag (نوافذ منبثقة/popunder) كانت مستخدمة سابقاً وتمت إزالتها بالكامل من كل الصفحات —
هذا النوع من الإعلانات يخالف صراحةً سياسات ناشري Google ويقلل فرص قبول الموقع في AdSense.

ملاحظة: أي ملف `sw.js` (Service Worker) على السيرفر غير مستخدم في هذا الإصدار ويُفضّل حذفه.
