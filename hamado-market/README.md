# Hamado Market — دفتر ديون الدكان

تطبيق أندرويد (APK) لتسجيل ديون زبائن الدكان وسجل الخبز اليومي، بديلاً عن الدفتر والقلم.
**كل البيانات تُحفظ داخل الهاتف** ويعمل التطبيق بالكامل بدون إنترنت.

---

## المزايا

### الرئيسية — كل المدينين أمامك
- بطاقات للزبائن مرتّبة تلقائياً: الأكثر ديناً في الأعلى.
- إجمالي المستحق لك، وعدد الزبائن، وعدد المدينين والمسدَّدين — في شريط واحد.
- تبويبات: الكل / عليهم دين / مسدَّدون، مع بحث فوري.

### التسجيل السريع (ثلاث خطوات)
1. اكتب أول حرفين من الاسم → تظهر الاقتراحات فوراً مع رصيد كل شخص.
2. اختر «دين جديد» أو «تسديد دفعة»، واكتب المبلغ (أو اضغط مبلغاً جاهزاً).
3. احفظ.

البحث يتجاهل فروق الهمزات والتاء المربوطة والألف المقصورة: كتابة **احمد** تجد **أحمد**،
و**فاطمه** تجد **فاطمة**. ولا يُنشأ زبون مكرّر بسبب اختلاف الهمزة.
إن لم يكن الاسم مسجّلاً، يظهر خيار «إضافة كزبون جديد» ويُنشأ تلقائياً عند الحفظ.

### صفحة الزبون
- الرصيد الحالي بوضوح، ولون يوضّح: عليه دين (أحمر) أم له رصيد (أخضر).
- ثلاثة أزرار: **دين** · **دفعة** · **سدّد الكل** (يسجّل دفعة بقيمة الرصيد كاملاً).
- سجل الحركات كاملاً مقسوماً بالأيام، مع **تعديل** أو **حذف** أي حركة خاطئة.
- زر اتصال وواتساب مباشر إن أُدخل رقم الهاتف.
- تعديل الاسم/الهاتف/الملاحظة، أرشفة الزبون، أو حذفه بكل سجلّه.

### دفتر الخبز
- اختر الزبون، حدّد عدد الربطات بزرّي + و −، واختر: **دفع الآن** أو **على الحساب**.
- إن كان «على الحساب» **يُضاف المبلغ تلقائياً إلى دين الزبون** — بلا أي خطوة إضافية.
- إحصائيات اليوم: عدد الربطات، المدفوع، ما على الحساب، وإجمالي اليوم.
- يمكن التنقل بين الأيام، وتبديل حالة الدفع لاحقاً (ويُعدَّل الدين تلقائياً معه).

### لوحة الإدارة (محمية برمز)
- الرمز الافتراضي **1234** — غيّره فوراً من داخل اللوحة.
- إعدادات المتجر: الاسم، رمز العملة، سعر ربطة الخبز.
- الإعلانات: شريط نصي متحرك أعلى الشاشة + بنرات في الرئيسية.
- إدارة كل الزبائن والبحث فيهم.
- النسخ الاحتياطي (تفصيله أدناه).
- منطقة خطر: حذف سجلات الخبز أو حذف كل البيانات.

### النسخ الاحتياطي
| الطريقة | ماذا تفعل |
|---|---|
| **حفظ في الجهاز** | يكتب ملف `hamado-backup-YYYY-MM-DD.json` في مجلد التنزيلات |
| **مشاركة / Google Drive** | يفتح قائمة المشاركة، فترفعه إلى Drive أو ترسله بواتساب |
| **تيليجرام** | يرسل الملف إلى بوتك مباشرة (توكن البوت ومعرّف الدردشة من اللوحة) |
| **نسخة يومية تلقائية** | عند تفعيلها، تُرسل نسخة لتيليجرام أول مرة تسجّل فيها كل يوم |
| **استعادة** | اختر ملف نسخة احتياطية ليُستبدل به كل المحتوى الحالي |

## التثبيت على الهاتف

1. نزّل ملف `HamadoMarket.apk`.
2. افتحه — قد يطلب أندرويد تفعيل «السماح بالتثبيت من هذا المصدر»، فعّلها.
3. ثبّت، وافتح التطبيق. لا يحتاج أي إعداد: يبدأ فارغاً وجاهزاً.

> التطبيق موقَّع بمفتاح تطوير (debug key) لأنه يُوزَّع خارج Google Play.
> هذا طبيعي تماماً للتثبيت المباشر، لكنه يعني أن أندرويد سيعتبره «مصدراً غير معروف» أول مرة.

## ملاحظات صريحة عن الأمان والبيانات

- **رمز الإدارة ليس تشفيراً.** هو يمنع العبث العابر بلوحة الإدارة على الهاتف نفسه فقط.
  من يملك الهاتف ولديه معرفة تقنية يستطيع قراءة قاعدة البيانات المحلية. لا تعتمد عليه
  لحماية أسرار حسّاسة.
- **البيانات داخل الهاتف فقط.** إن ضاع الهاتف أو حُذف التطبيق بلا نسخة احتياطية، تضيع
  البيانات. فعّل النسخة اليومية لتيليجرام أو خذ نسخة يدوية كل فترة.
- **توكن بوت تيليجرام** يُحفظ داخل الجهاز كما أدخلته. من يفتح التطبيق يستطيع رؤيته من
  لوحة الإدارة، فاستخدم بوتاً مخصّصاً لهذا الغرض فقط.
- الإنترنت مطلوب **فقط** لإرسال النسخة الاحتياطية إلى تيليجرام. كل شيء آخر يعمل دون شبكة.

## للمطوّرين — البناء

```bash
cd hamado-market
./gradlew :app:assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

يحتاج JDK 17 و Android SDK (platform 34, build-tools 34).
البناء الآلي يجري على GitHub Actions عبر `.github/workflows/build-apk.yml`،
وينشر الـ APK في Release جاهز للتنزيل.

### البنية
```
hamado-market/
├── app/src/main/
│   ├── assets/www/          تطبيق الويب (هو الواجهة الفعلية)
│   │   ├── index.html
│   │   ├── app.css          هوية "منتصف الليل + اليشم"
│   │   └── app.js           المنطق + IndexedDB
│   ├── java/com/hamado/market/
│   │   ├── MainActivity.java       غلاف WebView
│   │   ├── NativeBridge.java       حفظ/مشاركة/تيليجرام
│   │   └── HamadoFileProvider.java مشاركة ملف النسخة
│   └── res/                 الأيقونات والثيم
└── build.gradle             بلا أي اعتمادية خارجية
```

**لماذا `https://hamado.local` وليس `file://`؟** لأن WebView يمنع IndexedDB على أصل
`file://`، ما يعني ضياع كل البيانات. لذلك يعترض `MainActivity` الطلبات ويخدم نفس
الملفات تحت أصل `https` وهمي داخلي، فتعمل قاعدة البيانات المحلية بشكل موثوق.
